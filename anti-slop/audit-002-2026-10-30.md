# Audit desain ulang Cineplex

Mode AFTER, pilihan sesi pengguna. Pengguna secara eksplisit mengizinkan
perombakan visual dan UX serta pembuatan DESIGN.md. Tidak ada commit/push.

## Penemuan dan batas implementasi

Frontend awal adalah satu halaman HTML dengan style dan script inline, dilayani
oleh HTTP gateway Python yang meneruskan RPC ke gRPC. Tidak ada framework,
router, UI library, akun, atau pembayaran. Tiga jadwal demo, kursi A1-D5,
request ID persisten, retry dan streaming adalah fitur asli yang dipertahankan.
Tidak ditemukan DESIGN.md lokal; starter skill dibaca sebagai referensi awal,
lalu diganti dengan design system spesifik produk atas permintaan pengguna.

Masalah awal: hero terlalu besar, glow dan nested panel mendominasi, denah
meregang mengikuti sidebar, teks kecil, metadata film buatan, dan informasi
teknis terlalu dominan pada langkah reservasi. Referensi visual berasal dari
screenshot pengguna dan pemeriksaan sumber aplikasi.

## Arah dan kritik desain

Foyer terang lilac / auditorium plum / kursi terpilih kuning tiket. Daftar jadwal
tidak memakai tiga kartu setara di desktop; auditorium menjadi satu fokus,
sedangkan formulir berupa slip tiket. Manrope dipakai untuk keterbacaan angka
dan bentuk huruf terbuka. Dials ENERGY 2 / RHYTHM 2 / MOTION 1.

Kritik setelah render: caption pemasaran di atas judul dipotong; metadata genre,
durasi dan rating yang tidak ada di API dihapus; kuning pada tiket kosong diganti
netral agar pilihan kursi tetap menjadi fokus. Fokus keyboard yang hilang ketika
jadwal dirender ulang diperbaiki. Link skip memakai posisi di luar layar sampai
difokuskan, tanpa transform yang menghasilkan artefak screenshot. Cache aset
lama ditemukan saat QA; versi query pada CSS/JS ditambahkan.

## File dan perilaku

- DESIGN.md: identitas, rationale, tokens, tipografi, grid, breakpoint, komponen,
  motion, a11y, serta do/don't spesifik reservasi.
- web/index.html: header, navigasi anchor, programme, auditorium, tiket/form,
  feedback, UUID disclosure, tools disclosure, log, footer dan live region.
- web/static/css/app.css: satu sistem CSS dengan token, tanpa kit/dependency baru.
- web/static/js/app.js: fungsi frontend yang sama dengan data/API asli;
  state UUID/payload tetap dipertahankan untuk hasil yang belum diketahui.
- tests/test_web_state.js: membaca script eksternal; tambahan pemeriksaan error
  koneksi dan jadwal kosong. Backend, schema, proto dan endpoint tidak diubah.

## Bukti verifikasi

- 33 automated test Python lulus, 14,316 detik.
- Node state tests lulus: REJECTED menghasilkan UUID baru, unknown outcome
  mengulang payload/UUID sama, klik ganda dicegah, error dan empty state tampil.
- node --check app.js berhasil; git diff --check tidak menemukan error.
- npx @google/design.md lint DESIGN.md, exit 0 tanpa error/warning.
- Browser: pilih film dengan Enter, pilih B3 dengan Enter, isi nama dan booking
  CONFIRMED, kursi berubah BOOKED, pesan hasil berisi booking ID nyata.
- Browser: deduplikasi lulus, race satu berhasil/empat ditolak, benchmark
  1/5/20 client menghasilkan tabel angka dari server; detail UUID, buat ID baru,
  bersihkan log, navigasi anchor dan disclosure diuji.
- Browser error console kosong pada pemeriksaan.
- Responsive final: viewport/client/scroll width 320/305/305, 375/360/360,
  900/885/885, 1440/1425/1425. Selisih 15px adalah scrollbar. Semua tanpa overflow
  horizontal. Pada 320px batas tiap panel berada pada x=12 sampai x=293.
- Seats berukuran 44x44 pada mobile dan 48x46 pada desktop/tablet.
- Fokus film setelah pergantian jadwal tetap pada mc-SCH003 dengan outline solid.
- Screenshot final tersimpan di .tmp/cinema-redesign-{320,375,900,1440}.png.
  File sementara tersebut tidak masuk Git.

## Delivery gate untuk scope redesign

- PASS R-02: copy frontend baru tidak memakai em dash atau jargon pemasaran.
- PASS R-03/R-32/R-39: empat viewport diperiksa, kontrol native, target sentuh
  >=44px, skip link, label, selected/disabled state dan fokus keyboard tersedia.
- PASS R-17/R-18/R-36/R-38: angka kursi dan hasil uji berasal dari server; tanggal
  dari show_time; film dan harga simulasi dinyatakan; tidak ada testimoni/claim baru.
- PASS R-23/R-24/R-26: tidak membuat asset/logo baru; gambar lama dipakai ulang;
  navigasi menuju bagian nyata dan kontrol utama diuji langsung.
- PASS R-25: rasio teks muted/background 4,69; muted/paper 5,23; white/primary
  8,15; teks auditorium 7,70-10,50; ink/ticket 9,29; border seat/surface 4,71;
  feedback success 5,30, danger 5,94, warning 6,05. Dihitung memakai luminansi sRGB.
- PASS R-27/R-35: loading tools, booking sukses, input disabled dan stream nyata
  diperiksa di browser; empty/error/retry diuji otomatis. Tidak mengklaim uji manual
  untuk setiap variasi kegagalan jaringan.
- PASS R-33/R-34/R-40: UI ditulis langsung dalam source; satu tema konsisten,
  tidak ada dark-mode toggle setengah jadi; ukuran poster eksplisit; script defer;
  font memiliki fallback sistem dan tidak memblokir fungsi.
- PASS purpose/liveliness: tiap keputusan utama dijelaskan dalam DESIGN.md;
  tiga jenis area berbeda, satu fokus auditorium, warna pilihan terbatas pada
  tiket/kursi; tidak ada glow, hero ilustratif besar atau animasi berulang.

## Batas yang tetap berlaku

Layout diperiksa melalui viewport browser, bukan perangkat fisik. Manrope dapat
diambil dari Google Fonts; Segoe UI/sans-serif tetap berfungsi tanpa jaringan.
Demo dua komputer dan Docker berada di luar verifikasi visual ini. Tidak ada
perubahan autentikasi, pembayaran atau arsitektur backend. Hasil ini merupakan
verifikasi UI dan regresi fungsi, bukan sertifikasi WCAG formal.
